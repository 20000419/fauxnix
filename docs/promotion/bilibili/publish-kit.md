## 1. 标题候选(16 个,分四组)

### 悬念型(钩子不解开就不舒服)

1. **《两条 bash 命令的事,AI 烧了 9 次调用、7 次报错、114 秒》**
   点击逻辑:数字反常制造悬念——两条命令凭什么值 114 秒?答案(T4 验尸)是全片最好的微叙事,标题即承诺过程感。
2. **《你的 AI 编程助手在 Windows 上变笨了,而且不是模型的锅》**
   点击逻辑:归因反转。用户日常骂模型,这里说它被冤枉了——"那怪谁"的悬念直接拉点击;目标人群(Windows 上用 agent 的开发者)人人有体感。
3. **《几万台没屏幕、没键盘的 Mac mini,正在决定你的 AI 好不好用》**
   点击逻辑:反常画面(没屏幕的电脑买来干嘛)+ 与"你"的利益关联,双钩。新闻向但不靠标题党,正文有"据广泛报道"兜底。
4. **《我们给 AI 的命令行装了个"翻译官",它突然不犯傻了》**
   点击逻辑:"翻译官是什么、怎么装、为什么灵"三连悬念;口吻克制,适合账号长期人设。

### 数字冲击型(数字即标题)

5. **《实测:同一模型写 PowerShell,慢 2.5 倍、错 14 次》** ⭐ 首推
   点击逻辑:"实测"是合规前缀也是信任前缀;2.5× 与 14 次双数字对撞,目标人群无法忽略。封面直接复用这组数。
6. **《302 秒 vs 96 秒:一个模型被 PowerShell 拖垮的全过程》**
   点击逻辑:kimi-k2-thinking 的极端对照,"全过程"承诺验尸细节;比"3.1 倍"更有画面。
7. **《7 个模型全测了一遍:这口"降智税",谁都逃不掉》**
   点击逻辑:全量覆盖暗示严谨;"降智税"是可弹幕化的记忆点,利于评论区玩梗二次传播。

   点击逻辑:工程信誉数字流,吸引硬核开源受众;与前几条错开,适合数据向观众占比高时使用。

### 冲突对立型(站队即点击)

9. **《bash vs PowerShell:AI 只会写前者,你的电脑只认后者》**
   点击逻辑:天然对立结构,bash 党与 PowerShell 党都有立场,评论区自带辩论流量。
10. **《不装 WSL、不用 Git Bash:让 Windows 原生说 bash 的第三条路》**
    点击逻辑:同时挑战两个主流方案,"第三条路"给出新解期待;前置否定句筛选出最痛的那批观众。
11. **《Git Bash 都搞不定的中文编码,这个项目搞定了》**
    点击逻辑:挑战权威工具印象;GBK 文件 `grep 连接` 实测 1 vs 0 命中撑得住这句话,中文区观众独有益点。

    点击逻辑:口号冲突 + 技术奇观(常驻 host 把 powershell.exe 变 RPC 服务器),硬核受众点击欲最强的一条。

### 新闻热点型(必须带诚实前缀)

13. **《据广泛报道,OpenAI 囤了几万台 Mac mini 训练 AI——Windows 用户怎么办?》**

## 5. 分区建议

**投 科技 > 野生技术协会,不投 科技 > 数码。**

- 数码区的内容契约是消费电子产品评测(手机、耳机、笔电、外设),观众预期是"买不买"。开发工具内容进去 = 预期错配,完播率被算法惩罚,评论区还会出现"这和我有什么关系"的无效流量。
- 野生技术协会是"自制工具 / 折腾 / 硬核小项目"的集散地:命令行美学在这里不是缺点而是滤镜,"报错验尸""字节级对拍"这类内容弹幕文化契合;腰部视频竞争密度低于数码区,被捞概率更高。
- 取舍代价:野生技术协会天花板流量不如数码区。但本视频的目标是精准转化(star、npm 安装、MCP 接入),不是泛曝光——错配的曝光对转化是负资产。

## 9. 防杠评论预案(5 条)

**杠点 1:"为什么不用 WSL?"**
口径:官方划界写在项目文档里——需要真 bash 工具链(git 脚本、devcontainer、完整 POSIX 语义)就用 WSL,视频 14:10 明说。fauxnix 只解决"agent 的 shell 工作"这一个场景:不引入第二文件系统、不改变 Windows 原生语义、评分与生产环境一致。"Not for everyone"是项目自己写进文档的第一句话,不是被杠出来的补丁。

**杠点 2:"n=1 也叫测试?"**
口径:大方认——不是统计结论,是方向性证据,简介和视频里都标注了;任务脚本和原始数据全在仓库 docs/,欢迎复跑。这个项目的正确性也不靠 benchmark 撑:126 条语料与真 Git Bash 做字节级三路对拍(≥95% 一致才放行,每周 CI),271 项测试每次 push 全跑。复跑出不同结论欢迎贴出来,打中了我们修。

**杠点 3:"Codex 上更慢你怎么不说?"**
口径:这点不用挖,我们自己写在简介里了——Codex/Kimi harness 上贵 19–34%,因为那两个模型本来就擅长打包 one-shot;换来的是干净错误、cd 持久化、POSIX 路径。Claude Code 上打平略快(142.7s vs 163.9s)。值不值由场景定,我们把缺点放在明面上,就是为了让你不用猜。

**杠点 4:"Mac 新闻是假的吧?"**

**杠点 5:"PowerShell 明明很强,是你们不会用"**
口径:同意前半句——面向对象管道、.NET 互操作都强,这不是"PowerShell 好不好"的问题,是"模型会什么"的问题:训练语料里 bash 占主导,跨厂商 7 个模型全部复现同一方向的能力差。另外 fauxnix 的 `translate` 子命令本身就是学 PowerShell 的彩蛋:`fauxnix translate "find . -name '*.log' -mtime +7 -delete"`,看它翻成什么,比吵架有用。
